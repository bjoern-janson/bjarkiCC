3. Evidence limits

The DR profile is a provisional Classic baseline, not a verified Forever
server-rules specification. Its next-duration stages are 50%, 25%, immune.
The original 20s duration came from DRList's conservative upper value for a
stated 15-20s dynamic Classic reset. Version 0.3.1 implements the user's
requested start rule: each observed application starts or refreshes the timer;
CC duration, breaking and removal do not change that deadline. This timing
choice is not independent verification of Forever's server reset rule.
Version 0.4.8 preserves the default 20s application countdown and separately
defaults stage reset to a provisional 18s after CC ends. This value comes from
the supplied live trace's full Hibernate at 18.015s after observed removal,
not an upstream claim that Forever has a fixed 18s reset. Both settings are
independently configurable; see architecture.md for evidence and limitations.
Version 0.4.9 adds an original, bounded full-duration evidence correction after
another trace shows a full Hibernate only 15.5s after the prior accepted end.
It learns a same-victim/exact-spell baseline only after a 20s observed quiet
interval and considers a matching explicit LoC duration after a 15s end gap.
Those bounds follow the provisional Classic range, not verified Forever rules.
It does not copy Diminish's remaining-time ratio heuristic; correction remains
uncertain and is documented in architecture.md.
Version 0.4.11 adds an original bounded baseline-learning path from three
consecutive explicit same-spell durations D, D/2, D/4 under that provisional
three-successful-applications profile. It learns only after the full sequence,
does not infer current stages from remaining-time ratios, and keeps sequence
provenance and correction uncertainty. See architecture.md for eligibility.
The referenced Classic profile does not contain a separate Fear stage rule.

Most selected beta spell pages identify client build 1.60.1.70374. That is older
than the local target build 1.60.1.70425. Extracted client data and addon source
are not live-client or server-behavior validation.

The cooldown ranges are configured estimates, not guaranteed earliest/latest
bounds. Unmodeled talents, items, set bonuses, beta changes, missed casts, and
unobserved resets can invalidate them. HoJ's 45-60s range does not cover every
possible set bonus. Use overrides when verified in the client. Intercept's
20-30s range likewise does not include every possible equipment modifier.

The two reset families are historical and only clear tracked abilities:
Cold Snap 12472 -> Frost Nova 122.
Preparation 14185 -> Kidney Shot 408, Blind 2094, Gouge 1776.
Beyond those reset families and the shared shock family, no additional reset
or shared-cooldown relationships are inferred.

This is a curated starting registry, not complete coverage of every Forever
class ability, racial, item or pet ability. Item effects are classified for DR,
but item activation cooldown coverage is not complete. Spammable CC is
classified for DR but is not given a made-up cooldown. Blind and Death Coil have cooldown
presentation categories but no DR entry in the selected Classic mapping.
Loss-of-Control data alone cannot detect every root or Frost Shock slow; a
visible category in the options does not prove that the client supplies it.

Texture paths reference assets supplied by World of Warcraft. Blizzard media
is not redistributed in this package. World of Warcraft is a trademark of
Blizzard Entertainment, Inc.
